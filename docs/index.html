客户遍布全球，语言却不止英语Your customers are everywhere, and not all of them write English

复制、翻译、再粘贴Copy, translate, paste back

客户发来一段阿拉伯语或哈萨克语，复制到翻译网站，看懂了再写，写完再翻，再粘贴回 WhatsApp。一天来回几十次。A customer writes in Arabic or Kazakh. You copy it into a translation site, write your answer, translate it back and paste it into WhatsApp. Dozens of times a day.

一个数字翻错，就是一单的损失One wrong number costs an order

你看不懂自己发出去的外语。价格、数量、交期有没有被翻错，往往要等客户按错的数字下单才发现。You can't read the foreign-language text you just sent. If a price, quantity or lead time came out wrong, you may only find out when the customer orders on the wrong figure.

谁在等你的报价，答应了谁周五发 PI，哪个客户三天没回了。聊天记录一长，这些就埋在消息里。Who is waiting for your quote, whom you promised a PI by Friday, which customer has gone quiet for three days. In a long chat, all of it gets buried.

  • 打开聊天，译文自动出现在每条消息下方，标签写明是哪个引擎翻的。Open a chat and translations appear under each message, tagged with the engine used.
  • 觉得不准，点 ⇄ 换一个引擎重翻这一条。Not sure about one? Click ⇄ to retranslate it with another engine.
  • DeepL、通义千问 Qwen-MT、DeepSeek 三个引擎。一个出错（Key 无效、额度用完、服务故障），自动换下一个已填 Key 的引擎。Three engines: DeepL, Qwen-MT and DeepSeek. If one fails (invalid key, quota used up, outage), the next engine with a key takes over.
  • 孟加拉语、哈萨克语等 DeepL 不支持的语言，自动交给 AI 引擎。Languages DeepL doesn't support, such as Bengali and Kazakh, go to the AI engines automatically.

中文、纯数字、表情和链接自动跳过，不消耗额度；翻过的句子本地缓存，不重复计费。Chinese text, numbers, emoji and links are skipped. Translated sentences are cached locally, so you aren't charged twice.

3/5说快Reply fast

记住每个客户的语言，话术一键调出Each customer's language remembered, saved phrases one keystroke away

  • 切换客户，发送语言自动跟着变。用 Chrome 自带的语言识别，不消耗翻译额度。Switch chats and the reply language switches with you. Detection uses Chrome's built-in language detector, with no translation quota used.
  • 识别不对，或客户更习惯另一种语言，可以为这个客户手动固定。Wrong guess, or a customer prefers another language? Pin it for that chat.

常见问题Questions

要花钱吗？Does it cost anything?

插件本身免费、开源。翻译要用你自己申请的 API Key，费用直接付给服务商：DeepL 免费版每月有 50 万字符额度；Qwen-MT 和 DeepSeek 按用量计费，费用很低。翻过的句子会缓存，不重复计费。设置页会显示每个引擎本月用了多少字符，用量心里有数。具体价格以各平台官网为准。The extension is free and open source. Translation uses your own API keys, paid directly to the provider: DeepL's free plan includes 500,000 characters a month; Qwen-MT and DeepSeek are pay-as-you-go at low cost. Translations are cached, so the same sentence isn't charged twice. Settings show how many characters each engine used this month. Check each provider's site for current prices.

为什么不在 Chrome 应用商店里？Why isn't it on the Chrome Web Store?

目前还没有上架，所以要用“开发者模式”手动加载。这是 Chrome 和 Edge 自带的正规功能，按安装教程做大约 5 分钟。It hasn't been published there yet, so you load it in Developer mode, a standard feature of Chrome and Edge. The install guide takes about 5 minutes.

会不会自动替我发消息？Will it send messages for me?

不会。插件只把输入框里的中文换成译文，发不发、什么时候发，都由你自己按回车决定。作战卡的“起草这条消息”也只是填进输入框。No. It only replaces the text in the message box with the translation; you decide whether and when to press Enter. "Draft this message" on the battle card also only fills the message box.

装好了，但消息下面没有译文Installed, but no translations appear

先刷新 WhatsApp 网页，安装或升级后必须刷新。再打开插件设置，确认“启用插件”和“自动翻译收到的消息”已勾选，并且至少有一个引擎测试成功。还不行的话，可能是 WhatsApp 网页改版了：打开一个聊天，按 Alt+Shift+D 复制诊断信息（不含消息内容和电话），提交到 GitHub Issues。Reload WhatsApp Web first; that's required after installing or updating. Then open the settings and check that the extension and automatic translation are on and at least one engine passed its test. If it still doesn't work, WhatsApp Web may have changed: open a chat, press Alt+Shift+D to copy diagnostic info (no message text or phone numbers) and post it in GitHub Issues.

从 v0.9.0 起，如果 WhatsApp 改版导致插件认不出消息或输入框，页面左下角会直接弹出提示，可以一键检查插件更新、复制诊断信息。From v0.9.0, if a WhatsApp change means the extension can't find messages or the message box, a notice appears at the bottom left of the page with one-click update check and diagnostics.

Qwen-MT 提示“API Key 无效”Qwen-MT says the API key is invalid

最常见的原因是地域不一致：Key 和地域是绑定的。在设置页把地域改成你创建 Key 时所在的地域（推荐“华北2（北京）”），再点“保存并测试”。Usually the region doesn't match: keys are tied to a region. In settings, choose the region where you created the key (Beijing is recommended), then click Save & test again.

插件界面有英文吗？Is the extension's interface available in English?

有。从 v0.9.0 起，插件支持中文和英文界面：在设置页“界面语言 / Language”里选择。新安装时默认跟随浏览器语言，老用户升级后保持中文。欢迎在 GitHub 上贡献其他语言的界面翻译。Yes. From v0.9.0 the interface is available in English and Chinese: choose it under 界面语言 / Language in settings. New installs follow your browser language. Contributions for other languages are welcome on GitHub.

怎么升级？换电脑后数据怎么办？How do I update, or move to another computer?

从 v0.8.0 起，有新版本时插件图标上会出现红色的“新”，设置页顶部有更新内容和下载按钮。From v0.8.0, a red 新 badge on the icon tells you when an update is available, and the top of the settings page shows what changed with a download button.

升级：用新下载的文件覆盖原来的 extension 文件夹，在扩展程序页面点插件卡片上的 ⟳，再刷新 WhatsApp。一定要覆盖同一个文件夹，换文件夹加载会丢失已填的 Key 和设置。To update, overwrite your existing extension folder with the new files, click ⟳ on the extension card and reload WhatsApp. Always use the same folder: loading from a new one starts with empty settings.

换电脑或换浏览器：在设置页“备份与恢复”导出一个文件，到新环境导入即可，导入时与现有数据合并。To move, export a backup from Backup and restore in settings and import it on the new computer or browser; imports merge with existing data.

和应用商店里同名的 TradeLingo 是一回事吗？Is this the same as the other "TradeLingo" on the Chrome Web Store?
