TradeLingo 使用手册

TradeLingo 是一款 WhatsApp 网页版翻译插件：直接看懂客户消息，用中文写回复，一键翻译成客户的语言。插件可以接入 DeepL、Qwen-MT、DeepSeek 三个翻译引擎，为低压电器外贸沟通做了专门优化。

收到的消息 自动译成中文 发送的回复 一键翻译 + 回译核对 每个客户 自动记住语言 快捷话术 输入 / 调出 三引擎 出错自动备用 商机作战卡 把聊天变成生意 跟进提醒 不漏掉任何客户

01安装与升级

插件目前以“开发者模式”加载，不需要上架 Chrome 应用商店。

第一次安装

  1. 把收到的 tradelingo 仓库压缩包 解压，把其中的 extension 文件夹放在一个固定位置，例如 D:\Tools\tradelingo，之后不要删除或移动。
  2. 在 Chrome 地址栏输入 chrome://extensions 并回车，打开右上角的“开发者模式”开关。
  3. 点左上角“加载已解压的扩展程序”，选择刚才的 extension 文件夹。
  4. 点浏览器右上角的拼图图标，把“TradeLingo”固定到工具栏，方便以后打开设置。
  5. 点插件图标打开设置页，填写 API Key（见下一章），然后刷新 WhatsApp 网页。

升级到新版本

  1. 用新压缩包里的文件覆盖原来的插件文件夹。
  2. 在 chrome://extensions 找到插件，点卡片上的刷新按钮 ⟳。
  3. 刷新 WhatsApp 网页。如果跳过这一步，页面会提示“插件已更新或重载，请刷新 WhatsApp 页面”。

升级不会清除你已经填写的 Key、术语表、话术，也不会清除每个客户的语言记录。

02准备 API Key

至少填一个引擎就能用。推荐 DeepL 和 Qwen-MT 都填：收到的消息用 DeepL，发出的回复用 Qwen-MT。

引擎默认用途在哪里获取 Key费用参考特点
DeepL收到的消息deepl.com → 账户 → API Keys免费版 50 万字符/月速度快、稳定；不支持孟加拉语、哈萨克语等语言
Qwen Qwen-MT发送的回复阿里云百炼 → API Key（地域选“华北2（北京）”）flash：输入 0.7 元、输出 1.95 元 / 百万 Token专用翻译模型，支持 92 种语言，支持术语干预
DS DeepSeek翻译备用；商机作战卡只用它platform.deepseek.com → API Keys（需先充值）按用量计费能参考聊天上下文、可以控制语气

在设置页的对应卡片中粘贴 Key，点“保存并测试”。看到绿色的“连接成功”就说明可以用了。

03认识工具条

打开任意聊天，输入框右上方会出现插件的工具条。

1
引擎按钮：显示发送时使用的引擎（DeepL / Qwen / DS）。点一下切换到下一个已填写 Key 的引擎。
2
语言模式：自动 表示根据客户消息自动识别；手动 表示你为这个客户固定了语言；“默认”表示还没识别到，使用设置页里的默认语言。
3
发送语言：当前客户的回复会翻译成这种语言。在这里手动选择，就会固定这个客户的语言。
4
译：把输入框里的中文翻译成发送语言，快捷键 Alt + T。翻译后旁边会多出 ↩ 原文 按钮，点它可以恢复你写的中文。
5
话：打开快捷话术菜单，作用和在输入框输入 / 一样。
6
单（v0.6 起，在“话”的右边，红色）：打开商机作战卡，见第 09 章。有新消息还没分析时，按钮右上角会出现红点。

04看懂客户消息

打开聊天后，插件会自动翻译客户发来的消息，不需要任何操作。

  • 译文显示在消息气泡下方（绿色字），后面的小标签表示这条消息是用哪个引擎翻译的。
  • 觉得某条翻译不准确？点标签旁的 ⇄，用下一个引擎重新翻译这一条。
  • 中文消息、纯数字、纯表情和链接会自动跳过，不消耗翻译额度。
  • 引用回复时，插件只翻译回复内容本身，不会把引用框里的原话再翻译一遍。

05用外语回复

用中文写回复，翻译后核对一遍，确认无误再自己按回车发送。插件不会替你自动发送。

  1. 在输入框里用中文写好回复。
  2. 点工具条上的 译，或按 Alt + T。输入框里的中文会被替换成客户语言的译文。
  3. 看上方的黄色回译框：插件把译文再翻回中文，确认价格、数量、交期等意思没有走样。
  4. 确认无误后按 Enter 发送。如果想改中文原文，点 ↩ 原文 恢复后重新修改。

直接修改了译文？回译框会变淡，并标注“已修改”。点框里的 ↻，或按 Alt + B，会按输入框当前的内容重新回译。

DeepL 支持的语言用 DeepL 回译，速度快；孟加拉语、哈萨克语等用 Qwen-MT 回译。不需要回译时，可以在设置页关闭。

06每个客户的语言

插件用 Chrome 自带的语言识别判断每个聊天的语言，并为每个聊天单独记住。切换客户时，发送语言会自动跟着变。这个功能不依赖 DeepL，也不消耗翻译额度。

标签含义怎么来的
自动根据聊天内容自动识别的语言客户发来的消息权重最高；客户还没回复时，按你之前发出的外语消息判断
手动你为这个客户固定的语言，不会再被自动识别改掉在工具条下拉框里选了某种语言
默认还没识别到，使用设置页的“默认译成”聊天里还没有外语消息（例如只有中文）
  • 手动指定：例如哈萨克客户其实更习惯俄语，就在下拉框里选“俄语”，以后这个客户一直用俄语。
  • 取消手动：在下拉框最上方选 “↺ 恢复自动识别”。
  • 英语客户：会沿用你在设置页选的英语变体（美式或英式）。
  • 插件只保存聊天编号的哈希值，不保存客户的电话号码。

07快捷话术

把报价、交期、付款方式这类常说的话存成中文模板，用的时候自动翻译成当前客户的语言。

  1. 在输入框输入 /，弹出话术菜单。接着输入关键词可以筛选，例如 /交、/报价。
  2. 用 ↑ ↓ 选择，按 Enter 插入，按 Esc 关闭。也可以直接用鼠标点选。
  3. 插件把这条话术翻译成当前客户的语言，填进输入框；上方的黄色框会显示话术的中文原文。确认后按 Enter 发送。

编辑话术

在设置页的“快捷话术”里修改，每行一条：

关键词 | 中文内容

  • 关键词越短越好，方便用 / 筛选。
  • 内容里写 \n 表示换行。
  • 修改后马上生效，不用刷新页面。

请先修改示例话术。预置的 10 条里，交期天数、付款比例、认证名称都只是示例，请改成你们公司的实际情况，避免给客户错误承诺。

08术语表

让 AI 引擎每次都用你指定的专业译法，避免同一个产品出现好几种叫法。

在设置页的“术语表”里填写，每行一条：原文 = 译文（也可以用 →）。

  • Qwen 会把术语表作为“术语干预”参数，严格执行。
  • DS 会把术语表写进翻译指令。
  • DeepL 不使用术语表。

此外，插件已经告诉 AI 引擎这是“低压电器外贸对话”。MCCB、ATS、VFD 等型号，电流电压参数、价格和订单号都会原样保留。

09商机作战卡

点工具条上的红色“单”按钮，DeepSeek 会把当前聊天整理成一屏作战卡：这个单有多热、卡在哪里、你答应过什么、报过什么价，以及下一句该说什么。

卡片上有什么

项目说明
热度高 / 中 / 低，并写出判断依据。例如客户主动问付款方式、交期，就是强购买信号
阶段询盘、报价、样品、谈判、下单、售后
预估金额数量 × 单价（目标价或已报价）。数量或价格不明确时显示“未知”，不瞎猜
往来状态“客户在等你回复 6 小时”或“等待客户回复 3 天”，在本地计算，不消耗 Token
下一步推动成交最关键的一步，附一条写好的中文消息；点“起草这条消息”会翻译成客户的语言并填入输入框
卡点 / 需求 / 条款 / 客户成交障碍、产品规格与数量、贸易条款、客户类型（分销商、工程商等）
承诺记录双方说过的承诺。我方承诺今天到期或已逾期时标红
报价记录按时间排列的报价与还价，避免前后报价不一致
缺失信息成交前还需要弄清的信息，点“生成追问”就能写好一句追问
  • 每一项都有依据：鼠标停在带虚线的内容上，会显示它出自哪条消息、什么时间说的。
  • 手动修改：点任意一项的“编辑”就能修改。改过的项目会标上“✎ 已手动”，之后 AI 更新不会覆盖它。
  • 增量更新：有新消息时，“单”按钮上会出现红点。点“更新”只把新消息发给 DeepSeek，改动以“AI 更新建议”的形式列出，由你逐条采纳或忽略。
  • 摘要页：切到“摘要”标签，可以看到进展要点，以及“我方要做 / 等客户”两类待办。
  • 复制：“复制文本”适合发给同事，“复制到 Excel”会带上表头，可以直接粘贴到表格里。

只分析屏幕上加载出来的消息（最多 80 条）。聊天较长时，先往上滚动加载更多历史消息，再点“生成”。

费用：每次生成约 0.01 元，每次更新约 0.005 元（deepseek-flash 高峰时段价格）。发送前电话号码会被打码。

10今日跟进与提醒

把所有作战卡按“预估金额 × 热度 × 紧急度”排序，并在需要你行动时弹出桌面通知。排序和提醒都在本地计算，不消耗 Token。

什么时候会提醒你

  • 我方承诺或下一步今天到期、已经逾期（客户自己的承诺不提醒）。
  • 客户等你回复超过设定的时间（默认 4 小时，可选 2、4、8、24 小时）。插件会参考你打开聊天时看到的消息，以及左侧聊天列表里的未读数：就算你还没点开那个聊天，也能知道客户发来了新消息。如果你已经在手机上回复，列表里会出现勾号，提醒会自动解除。
  • 每日早报：每天到点后（默认 9 点）推送一条“今日跟进：N 个客户需要处理”，列出最紧急的前 3 个。

浏览器开着就每 15 分钟检查一次，不打开 WhatsApp 也能收到。同一件事一天只提醒一次，一次最多弹 4 条。点击通知会打开今日跟进页面。

装好后先点“发送测试通知”。如果没有弹出，请在 Windows 的“设置 → 系统 → 通知”中允许 Chrome（或 Edge）发送通知。

未读提醒只针对已有作战卡的客户，朋友和同事的聊天不会被打扰；读取聊天列表需要 WhatsApp 网页开着。

11备份与恢复

作战卡、话术、术语表和客户语言记录都只保存在这台电脑的浏览器里。建议定期导出备份。

  • 导出备份：生成一个 JSON 文件，包括作战卡、快捷话术、术语表、每个客户的语言记录和全部设置。
  • API Key 默认不导出。只在自己的电脑之间迁移时勾选“包含 API Key”，并妥善保管文件。
  • 导入备份：与现有数据合并，不会清空。同一个客户保留分析时间较新的作战卡，手动指定的语言优先。
  • 换电脑、换到 Edge 浏览器，或者重装插件之前，都可以先导出，再到新环境导入。

12引擎与自动备用

如果所选引擎出错（Key 无效、额度用完、账户欠费、服务器故障），插件会自动换下一个引擎，并在页面底部提示原因。

所选引擎例如 DeepSeek出错 → Qwen Qwen-MT→ DeepL→ DS DeepSeek
  • 只会切换到已经填写 Key 的引擎。
  • DeepL 不支持的语言（孟加拉语、哈萨克语、乌兹别克语、印地语、乌尔都语、波斯语、越南语、泰语、马来语、菲律宾语）会直接跳过 DeepL。语言列表里这些语言标有“（AI）”。
  • 翻译过的内容会缓存在本地，同样的句子再次出现时不会重复扣费。
场景推荐引擎原因
收到的大量消息DeepL速度最快，只要看懂意思就够了
给客户的正式回复Qwen行业术语准确，支持术语表，费用很低
语气要求高、需要结合前文DS能参考最近 8 条聊天，可以设置正式或友好的语气
孟加拉、中亚等小语种客户QwenDeepL 不支持这些语言

15常见问题

消息下方没有译文，工具条也不出现

1. 确认已经刷新 WhatsApp 页面。安装或升级插件后必须刷新。

2. 打开设置页，确认“启用插件”和“自动翻译收到的消息”都已勾选，并且至少有一个引擎测试成功。

3. 如果还是不行，可能是 WhatsApp 网页改版了。打开一个聊天，按 Alt + Shift + D，把复制出来的诊断信息发给开发者。诊断信息不包含任何消息内容。

提示“插件已更新或重载，请刷新 WhatsApp 页面”

你在 chrome://extensions 里刷新过插件，旧页面和插件的连接断开了。刷新一下 WhatsApp 页面就好。

Qwen-MT 提示“API Key 无效”

最常见的原因是地域不一致：北京地域的 Key 只能配合“华北2（北京）”使用。请在设置页把地域改成你创建 Key 时所在的地域，再点“保存并测试”。

提示“阿里云账户欠费”或“DeepSeek 账户余额不足”

到对应平台充值即可：阿里云在控制台右上角“费用”→“充值”，DeepSeek 在 platform.deepseek.com。充值前，插件会自动改用其他已填 Key 的引擎。

DeepSeek 提示“连接卡住”或“响应超时”

看测试结果卡在哪一步：第 1 步失败说明电脑连不上 DeepSeek，常见原因是 VPN 或代理把流量绕到了国外，可以把 deepseek.com 设为直连；第 2 步失败多半是 DeepSeek 服务器繁忙，可以到 status.deepseek.com 查看服务状态。

提示“本月 DeepL 字符额度已用完”

DeepL 免费版每月有 50 万字符额度。用完后，插件会自动改用 Qwen-MT。也可以在设置页把“收到的消息”的引擎直接换成 Qwen-MT。

某个客户的语言识别错了

在工具条的语言下拉框里手动选对，这个客户就会固定为该语言，标签变成“手动”。

收不到跟进提醒

先在设置页点“发送测试通知”。如果没有弹出，请在系统通知设置中允许 Chrome / Edge 发送通知；同时确认“跟进提醒”已勾选，并且客户已经生成过作战卡。浏览器需要保持运行。

作战卡漏掉了早期的内容

作战卡只分析屏幕上已经加载出来的消息（最多 80 条）。先在聊天里往上滚动，加载出更早的消息，再点“重新生成”。

修改了术语表，旧消息会重新翻译吗？

会。使用 Qwen-MT 或 DeepSeek 翻译的消息会自动按新术语表重新翻译，不需要清空缓存。DeepL 不使用术语表，所以它的译文不会变。

16隐私与费用

  • 商机作战卡只在你点击“生成”或“更新”时，把当前聊天最近最多 80 条可见消息发给 DeepSeek，电话号码会先打码。
  • 跟进提醒在本地计算，通过系统通知显示，不会发送到任何地方。
  • 消息内容只会发送给你选择的翻译服务商（DeepL、阿里云或 DeepSeek），不会发送到其他地方。涉及敏感报价时，可以在发送前切换引擎。
  • API Key、术语表、话术和客户语言记录都只保存在你这台电脑的浏览器里。
  • 客户语言记录只保存聊天编号的哈希值，不保存电话号码。
  • 插件只负责翻译，不会替你发送任何消息，账号风险很低。
